# Super 30: Python Loop Challenges

A modular repository containing independently executable solutions for Python loop challenges, covering data processing, stateful control flow, pattern generation, and terminal simulations.

---

## Program Index & Sample I/O

| Filename | Description | Sample Input | Sample Output |
| :--- | :--- | :--- | :--- |
| `01_total_transaction_value.py` | Sum of transaction list without `sum()` | *None* | `The total is: 7050` |
| `02_highest_lowest_transaction.py` | Min & max values without built-ins | *None* | `The highest is: 2300`<br>`The Lowest is: 100` |
| `03_average_temperature.py` | Average calculation from readings | *None* | `The average is : 35.14` |
| `04_marks_distribution.py` | Multi-bracket score classification | *None* | `90+: 2`<br>`75-89: 2`<br>`50+: 2`<br>`Below 50: 1` |
| `05_login_attempts.py` | 3-attempt credential limiter with `for-else` | `1234` | `Login Successfully` |
| `06_filter_products.py` | Dictionary value threshold filtering | *None* | `Laptop`<br>`Phone` |
| `07_user_input_list.py` | Dynamic list population via 10 input passes | `1, 2, 3 ... 10` | `Collected numbers: [1, 2, ...]` |
| `08_char_frequency.py` | Character frequency mapping without `Counter` | *None* (`"Sanjeet"`) | `S -> 1`<br>`e -> 2` ... |
| `09_second_largest.py` | Second largest extraction in a single traversal | *None* | `The largest is: 2300, The second largest is: 1500` |
| `10_palindrome_loop.py` | String reversal & palindrome comparison | `madam` | `madam is palindrome` |
| `11_number_pattern.py` | Nested loop numeric triangle generator | *None* | `1`<br>`12`<br>`123` ... |
| `12_atm_simulation.py` | Stateful interactive banking interface | Choice `1` | `Your account balance is: 10000.00` |

Each exercise is completely independent and can be executed without dependencies:

python 02_highest_lowest_transaction.py
